# Architecture Decision Records

This folder records the architecture decisions of the project using [MADR 4.0.0](https://adr.github.io/madr/), based on its [minimal template](https://github.com/adr/madr/blob/4.0.0/template/adr-template-minimal.md).

## Conventions

* One decision per file, named `NNNN-title-with-dashes.md` (e.g. `0002-use-postgresql-as-database.md`).
* Numbers are sequential and never reused.
* Start a new ADR from [adr-template.md](adr-template.md).
* ADRs are not rewritten once accepted. To change a decision, write a new ADR and mark the old one as superseded, e.g. a line at the top: `Superseded by [ADR-0005](0005-....md)`.
* Add every new ADR to the index below.
