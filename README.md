# Achievements

A personal app to log achievements by category and look back at them on a timeline, as a way to value what has already been accomplished.

It is also a study and portfolio project, built in small, feature-driven increments with CI, tests and static analysis from the start.

## Stack

- **Backend:** Java 25, Spring Boot 3, PostgreSQL, Flyway, Gradle
- **Android:** Kotlin, Jetpack Compose (Material 3), Hilt, Retrofit

## Repository layout

backend/   Spring Boot REST API
